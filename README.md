# Study & Scroll: Social Media Use and cGPA

STA304H5 Group 18 (UTM, Fall 2026): Sasha Ampuero, Angela Chen, Prativa Ghimire, Edward Hsu, Ali Rashid

**Live app:** https://01a1ecba-7bac-60b2-464d-3c5b7a633e74.share.connect.posit.cloud/

An interactive R Shiny app exploring whether daily social media use and study time relate to self-reported cGPA, using our survey of 64 STA304H5 students.

The app code is in `sta304-shiny/`. To run it locally, please open `app.R` in RStudio and click **Run App**.
